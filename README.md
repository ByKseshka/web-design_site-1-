# Тьма и Свет — кооперативный платформер

Полноценный 2D-платформер на чистом JavaScript (ES-модули), Canvas 2D и Web Audio API.
Без сторонних библиотек. Работает в любом современном десктопном браузере.

## 🎮 Об игре

Два героя — **Тьма** и **Свет** — должны вместе пройти 12 Храмов Равновесия.
Каждый герой имеет уникальные способности:

- 🌑 **Тьма**: рывок (dash), не может ходить по светлым зонам.
- ☀️ **Свет**: двойной прыжок, не может ходить по тёмным зонам.

Цель — собрать ключи, кристаллы, открыть двери и добраться до цели обоими героями.

## 🕹️ Управление

| Действие | Тьма | Свет |
|---|---|---|
| Движение | A / D | ← / → |
| Прыжок | W | ↑ |
| Двойной прыжок | — | ↑ в воздухе |
| Рывок (dash) | Shift | — |
| Подбор/бросок предмета | E | E |
| Пауза | Esc | Esc |
